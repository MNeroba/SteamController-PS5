### P1-HOOK-ROLLBACK-01 update — M1-208 (2026-10-09)

Status is now **PARTIALLY FIXED (HOST); TARGET ABI/HARDWARE UNVERIFIED**. The worker's shutdown path sends best-effort neutral input/audio-off state, retries owner-checked removal five times, then joins with `GAME_HOOKS_STOP_ROLLBACK_PENDING`; central shutdown completes its own cleanup, logs the retained target gateway and returns nonzero. This bounds the retry count, not the latency of an individual remote syscall. If remote writes remain unavailable, target-resident gateway code is deliberately not unmapped; existing input stale-read and audio heartbeat limits are the fallback until game exit/later cleanup. Source audit found no production callers of ShellUI patch/unpatch APIs; the distinct disconnect function remains behind the disabled-by-default DualSense hand-off policy. Still blocked: PS5 remote memory semantics/call latency, stale-input/audio callback timing, process exit and H-12/stock-DualSense behavior. Do not call the legacy ShellUI unpatch speculatively.
