## Current established source research

- PuckbridgePS5 has source paths for SC 2026 via official Puck and wired USB, profiles, touch, gyro, motion, haptics, and game hooks. FW 13.60 support remains an upstream claim until reproduced. Its upstream portal was passwordless; this derivative requires a private API bearer token and filters accepted peers to local IPv4 address ranges before parsing, but neither change has been tested on PS5 hardware. The portal still binds all IPv4 interfaces and uses plaintext HTTP. The upstream limitation of one SC active through Puck remains.
- OmniPad-PS5 has USB hotplug and multi-pad virtual slots, but no active direct BT as of v1.0.4; relevant security, buffer and lifecycle issues identified at source level. Status: `VERIFIED_CODE` for observed patterns, hardware claims still upstream.
- SteamlessController pin `1de3f7a40ec9f73b0683898e60c7cc8a5695e0b0` (`src/steam/SteamController.h`, MIT at that pin) defines the vendor usage page `0xFF00`, controller usage `0x0001`, and Puck dock usage `0x0002`; this is source evidence, not a captured descriptor. SDL, SteamlessLink and OpenPuck remain protocol references; **Puck radio != BLE GATT**.
- SharpProspero describes 17 libSceBluetoothHid entry points, but not a demonstrated arbitrary BLE Central/GATT API on FW 13.60.
- PS5 Linux internal Bluetooth evidence and merged btusb/xHCI fixes do not imply safe ProsperoOS shared-radio access; Bluetooth reported unstable in Linux PR.
- BTstack-dev reported a BLE keyboard refused by retail PS5; stock BLE-HOGP pairing cannot be assumed supported.
- No actual FW 13.60 native BLE advertising, GATT subscription or Steam Controller direct BLE reports verified.
