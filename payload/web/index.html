Quick setup

Recommended: play with the Steam Controller as your main controller, with game rumble sent to it. Turn the Steam Controller off at any time and your DualSense takes over; wake the Steam Controller with its Steam button to switch back.

Pause Puckbridge

Hold the Steam Controller's … button for 5 seconds, anywhere (in a game or on the home screen), to pause Puckbridge: the Steam Controller stops sending input and your DualSense works exactly as normal. Hold it for 5 seconds again to resume. The controller gives a long buzz when pausing and a short one when resuming.

Menu on the console

Switch profiles or remap a button without leaving the game. Messages appear as PS5 notifications.

  1. Bind Puckbridge menu to any button or activator (for example View → Long press). Press it to open or close.
  2. D-pad up/down chooses, left/right changes profile, A selects, B closes.
  3. To remap: pick Remap a button, press the button to change, then press the button it should act as. It saves to the current game's profile.

Game bridge check

Game vibration and DualSense-free input need to hook into the game's controller code (the PoorDS4 method). This check runs automatically about 8 seconds after a game starts. It only reads; nothing in the game is changed.
